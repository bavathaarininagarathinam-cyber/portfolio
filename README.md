# Bavathaarini- First-Year CSE Portfolio Website

A clean, modern, and responsive personal portfolio website built for a first-year Computer Science and Engineering undergraduate at the College of Engineering & Technology.

This portfolio showcases academic foundation, programming proficiencies in C, HTML, CSS, and JavaScript, hands-on student projects, and verified contact links.

---

## 🌟 Key Features

- **Semantic HTML5 Architecture**: Accessible structure with meaningful sectioning (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Modern Responsive Design**: Mobile-first responsive layout with Flexbox and CSS Grid that looks great on mobile phones, tablets, and desktops.
- **Dark Mode Support**: One-click theme toggle in the header with persistence using `localStorage` (remembers your choice across page reloads).
- **Smooth Navigation Scrolling**: Smooth animated scroll when clicking internal section anchor links.
- **Floating "Back to Top" Button**: Slides into view automatically when scrolling past 300px and returns to the top with a smooth glide.
- **Zero-Dependency Vanilla Code**: No heavy frameworks or build tools required—runs out-of-the-box in any modern browser.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic document markup and accessible metadata.
- **CSS3**: Custom properties (variables), Flexbox, CSS Grid, multi-stop gradients, and smooth transition physics.
- **JavaScript (ES6+)**: DOM manipulation, event listeners, smooth scrolling, and `localStorage` API.
- **Google Fonts**: Plus Jakarta Sans (Headings) and DM Sans (Body).

## 🌐 Deploying to GitHub Pages (Free Hosting)

Follow these steps to host your portfolio live on the internet for free:

### Method 1: Using the GitHub Web Interface (Easiest for Beginners)

1. **Create Repository**:
   - Log in to [GitHub](https://github.com).
   - Click the green **New** button to create a new repository.
   - Name your repository exactly: `<your-username>.github.io` (e.g., `bavathaarininagarathinam-cyber
.github.io`).
   - Set the visibility to **Public** and leave all checkboxes unchecked.
   - Click **Create repository**.

2. **Upload Your Files**:
   - On the new repository page, click the **uploading an existing file** link.
   - Drag and drop `index.html`, `style.css`, `script.js`, and `README.md` into the box.
   - In the "Commit changes" box, type: `Initial release of personal portfolio`.
   - Click **Commit changes**.

3. **Verify GitHub Pages**:
   - Go to **Settings** > **Pages** in your repository.
   - Under "Build and deployment", verify that the source is set to **Deploy from a branch** (Branch: `main`, Folder: `/ (root)`).
   - Click **Save**.

4. **Visit Your Live Website**:
   - Wait 1 to 2 minutes for GitHub to build your site.
   - Your website will be live at:
     ```
     https://<your-username>.github.io/
     ```
